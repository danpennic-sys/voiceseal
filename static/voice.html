VoiceSeal Capture

Dictate on-site. Review. Download JSON. Seal offline with the CLI.

Idle. Mic requires a user gesture and a supported browser (Chrome / Edge).

After download, seal with: python3 src/voiceseal.py --note your-note.json --out sealed.json then qg verify sealed.json. Core path is local: Web Speech API runs in the browser; no remote model required.
